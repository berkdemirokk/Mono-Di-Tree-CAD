# Synthetic curve-document experiment

`PatternPiece` in the existing core stores a point list and visual notches attached to contour vertex indexes. It cannot represent cubic controls, an independent open allowance path, source glyph definitions, their affine transforms or a source text path without loss. Persistence, rendering, grading and nesting depend on that point model. This experiment does not change the production model or connect to its import, export, nesting or plotter routes. A future integration would need explicit cubic/semantic model and persistence versioning, renderer support, editing/undo/transform rules and safety gates; none has been implemented here.

`synthetic-curves.v2` is a private, fixed-synthetic JSON contract. It retains three named piece roles; mm units; selected seam and allowance move/line/cubic/close operations; open or closed allowance state; intermediate annotation path; named notch anchors; SVG-rounded anchors and glyph transforms; and a source-to-current affine matrix per piece. It now additionally stores the six source SVG notch and marker definitions, the exact SVG-rounded annotation path, source textPath markup and ID, label, start/end marker IDs and annotation transform. Definitions are validated against fixed hashes from the observed local 4.10.2 source. The private v2 contract rejects the older v1 documents and changed, missing or unknown glyph definitions, unsupported metadata, inconsistent transforms or mismatched annotation geometry. Hash matching is not proof of license or source authenticity.

`synthetic-mark-reproduction.mjs` reconstructs a limited diagnostic mark-only SVG from a validated roundtripped document. Tests compare the recreated definitions, annotation path and text with the original generated SVG, and verify piece placement and glyph transform. This helper is not a CAD or production exporter. Source definitions are third-party material and their redistribution license remains unresolved. The sample `synthetic-curve-example.json` contains those definitions; it is a research artifact, not a released or legally cleared distribution.

## Remaining loss and gates

This is **not a lossless representation of the complete FreeSewing source or SVG**. The mandatory loss list names the source parts `breanna.base`, `breanna.frontBase`, `breanna.sleevecap`; hidden `saBase` and `sleevecap` paths; the three dart hints; both scalebox paths; and the `logo` snippet. Source object attributes, named points, `noop` operations, cutlist and other metadata, the complete SVG and source styling remain omitted. These categories are conservative across pieces and options. Removing or changing a mandatory loss entry fails closed. Exact source style, general SVG behavior, edge pairing, cut boundary, sewing fit and production validity are not established. All transferable, production, topology and license flags remain false, and the production gate always rejects. Document validation cannot establish the claimed source's authenticity.

The example generator accepts no external data. It uses one fixed synthetic draft with 10 mm allowance and source group translations. The front allowance is open and a front line has zero length. An explicit seam close does not prove simple topology or a valid cutting boundary. No personal data, CAD project or machine is touched.

Selected binary64 path coordinates and cubic controls roundtrip through JSON without flattening, subject to JSON negative-zero normalization. Affine mapping uses binary64 arithmetic and is not mathematically exact. SVG-rounded coordinates are matched to intermediate coordinates within 0.0051 mm per axis. For affine linear part `[a c; b d]`, `sqrt(2)*0.0051*sqrt(a²+b²+c²+d²)` mm is a conservative real-arithmetic bound on that input discrepancy; floating-point rounding is additional and not formally bounded. Per-axis validation uses corresponding row sums and a small numerical margin, not a certified tolerance or topology proof.

Tests exercise source/reproduction comparison, SVG definitions and text, composed and per-piece transforms, rotations, anisotropic scaling, open/missing allowance, altered definitions and geometry, unsupported types, duplicate IDs, missing fields, forged flags and singular matrices. FreeSewing and hooks attribution remains unresolved in `PUBLIC_LICENSE_RESEARCH.md`; production and plotter paths stay closed.
