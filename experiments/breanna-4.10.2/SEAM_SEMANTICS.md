# Local Breanna 4.10.2 seam and annotation evidence

This is an analysis of the installed local source and synthetic drafts, not a production or license approval. The front and back draft functions finish `paths.seam` with class `fabric` and keep `paths.saBase` hidden; when `sa` is nonzero, each creates a separate `paths.sa` from an offset of `saBase`, class `sa`. The sleeve constructs `paths.seam` with class `fabric`; when `sa` is nonzero it offsets that seam into a separate `paths.sa` with class `fabric sa`. The default fixed synthetic draft has no `paths.sa`. A second synthetic draft with `sa:10` confirms distinct paths in all three pieces. This difference is evidence of source semantics, not evidence that the offset is a validated cutting contour.

Front has `armholePitch` and `bustNotch` snippets using `notch`; back has `armholePitch` using `bnotch`; sleeve has `frontNotch` (`notch`) and `backNotch` (`bnotch`). Sleeve source uses the stored front/back armhole-to-pitch distances to place its corresponding marks. These names and definitions support an intended front/back correspondence, but we have not proved sewing fit, exact edge correspondence, orientation or placement tolerances. Snippets are source objects and are listed as omitted in the intermediate loss manifest; the preview neither carries nor displays their geometry.

Front calls the cut-on-fold macro with `grainline: true`; back and sleeve call the grainline macro. The annotation plugin creates a visible note path and stores a grain angle in its cutlist. Front source records a cut count of one on fold, back two on fold, and sleeve two from fabric. These source cutlist statements are not independently validated for a particular garment or transferred to the preview. The rendered annotation paths are classified as annotations in the intermediate model, not as a validated CAD grainline.

The experiment requires exactly one seam path per named piece, sets `cutBoundaryAvailable:false` and `transferable:false`, records topology as unverified, and rejects the extra `sa` source path. The SVG probe also rejects the sleeve's extra `fabric sa` path. No source seam, offset, notch, cutlist or SVG is approved for production, export or plotting; licensing remains unverified. No network or real measurements were used.

Evidence: installed `@freesewing/breanna/src/front.mjs`, `back.mjs`, `sleeve.mjs`, `@freesewing/plugin-annotations/src/grainline.mjs`, `cutonfold.mjs`, and `seam-semantics.test.mjs` in this experiment. The synthetic tests are version-specific and do not establish general FreeSewing behavior.
