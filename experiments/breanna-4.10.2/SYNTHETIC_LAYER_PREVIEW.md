# Synthetic layered display

This fixed synthetic example drafts Breanna 4.10.2 with an explicit 10 mm allowance and renders front, back and sleeve as self-contained, read-only HTML. Each piece retains its own source-local millimetre coordinates and cubic path operations; the original SVG stack/layout transforms are deliberately not applied. The display explicitly states this and does not imply a shared layout. It shows the source seam, the separate source allowance path, the source grainline or cut-on-fold annotation path, and colored circles at named notch anchors. Circles are diagnostic markers, not the source notch glyphs or their orientation. The front allowance path is open in this synthetic example and is labelled accordingly. The source front also has a zero-length line.

The adapter checks the observed part, path, annotation, and notch identities and classes and rejects unknown commands. It does not manufacture an allowance when source `sa` is absent; tests exercise a separate zero-allowance synthetic draft. It explicitly reports omitted original notch glyph/orientation, cutlist, source SVG layout, validated seam matching and cutting boundaries. It does not establish that the source paths are valid cutting contours, accurately offset everywhere, fit for sewing, licensed, or physically calibrated. Rendering for print is disabled; this is not an export or plotter tool. No external input, real measurements or network is used.

Tests compare the generated local coordinates and controls directly with independently drafted source objects, including all piece roles, notch names and defs; they test source-path versus rendered HTML coordinates, absent allowance, unknown classes and operations, and refusal of command-line input. The existing separate SVG transform probe tests placement transformations; this display intentionally leaves them unapplied.
