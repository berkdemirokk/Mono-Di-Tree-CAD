# Synthetic layered display

This fixed synthetic example drafts Breanna 4.10.2 with an explicit 10 mm allowance and renders front, back and sleeve as self-contained, read-only HTML. The common view applies the source SVG stack translations to every layer, in one millimetre coordinate system and the original viewBox. Separate detail panels retain source-local coordinates and are individually scaled. Only the observed FreeSewing 4.10.2 group hierarchy, mm viewport and translation-only profile is accepted; this is not a general SVG parser. The front allowance path is open in this example, and the source front has a zero-length line.

The source notch and bnotch glyph definitions and the grainline and cut-on-fold marker definitions are taken from the installed annotation package and required to match the generated SVG. The source SVG notch uses must have the observed scale-one transform; positions are matched to named source anchors within 0.0051 mm, and their SVG-rounded coordinates are retained. The source annotation path, marker identities, and rendered text are also required and preserved. Shape definitions are reused with namespaced identifiers; diagnostic colors, stroke widths and font styling are not source styling. The actual source labels are untranslated localization keys. Missing, changed, rotated, scaled or ambiguous supported marks cause rejection; unsupported styles and transforms are not inferred. The common view puts the marks, annotation paths and fabric layers under the same piece-group translation.

Seam and allowance geometry comes from the higher-precision intermediate object; source marker paths and coordinates use the SVG's rounded values. The adapter does not manufacture an allowance when source `sa` is absent. The display does not carry the cutlist or prove seam matching, exact offsets, cutting suitability, fit, licensing or physical print calibration. No real data, network, plotter or production export is used. The third-party license remains unverified, and the original glyph definitions are present in the experimental HTML; this is not cleared for redistribution.

Tests compare named source points, SVG geometry, mark identities and group translations, verify missing/altered glyphs, text and transforms fail closed, and cover absent allowance and unknown classes. The local result was inspected in a headless browser.
