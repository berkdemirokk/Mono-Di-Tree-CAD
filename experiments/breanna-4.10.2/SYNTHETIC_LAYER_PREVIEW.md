# Synthetic layered display

This fixed synthetic example drafts Breanna 4.10.2 with an explicit 10 mm allowance and renders front, back and sleeve as self-contained, read-only HTML. The common view applies the source SVG stack translations to every layer, in one millimetre coordinate system and the original viewBox. Separate detail panels retain source-local coordinates and are individually scaled; the display labels the distinction. Only the exact observed FreeSewing 4.10.2 group hierarchy, mm viewport and translation-only transform profile is accepted; this is not a general SVG parser. It shows the source seam, the separate source allowance path, the source grainline or cut-on-fold annotation path, and colored circles at named notch anchors. Circles are diagnostic markers, not the source notch glyphs or their orientation. The front allowance path is open in this synthetic example and is labelled accordingly. The source front also has a zero-length line.

The adapter checks the observed part, path, annotation, and notch identities and classes and rejects unknown commands. It does not manufacture an allowance when source `sa` is absent; tests exercise a separate zero-allowance synthetic draft. It explicitly reports omitted original notch glyph/orientation, cutlist, validated seam matching and cutting boundaries. It does not establish that the source paths are valid cutting contours, accurately offset everywhere, fit for sewing, licensed, or physically calibrated. Rendering for print is disabled; this is not an export or plotter tool. No external input, real measurements or network is used.

Tests compare the generated local coordinates and controls directly with independently drafted source objects, including all piece roles, notch names and defs; they test source-path versus rendered HTML coordinates, absent allowance, unknown classes and operations, and refusal of command-line input. Tests compare all common-view path controls and notch anchors with separately generated source objects plus independently read source translations, and reject unsupported units, nesting or transforms. SVG-rendered paths use source rounding while this visualization uses the underlying higher-precision source coordinates. Grainline arrowheads and annotation text, as well as source notch glyphs and orientations, are not displayed.
