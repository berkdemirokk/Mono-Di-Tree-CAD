# Synthetic SVG transform inspection

The probe uses a DTD-disabled XML reader on synthetic FreeSewing 4.10.2 SVG, identifies exactly one `class="fabric"` path for each of the three named pieces, and traverses its actual group ancestry. It applies SVG transform-list order and the outer physical viewport in millimetres. Supported transforms are matrix, translate, scale and rotate (including a rotation center); supported path commands are explicit absolute M, L, C and z/Z. The root accepts mm dimensions and viewBox with either default xMidYMid meet or preserveAspectRatio none. All other commands, transformations, relevant attributes and aspect alignment modes are rejected. Only empty stylesheet content is accepted; declarations and external references are not evaluated. Non-geometric annotation/definition content is ignored rather than interpreted.

Each reported box encloses transformed endpoints and cubic control points. It is conservative, not an exact Bézier-extrema box. The real generated SVG coordinates are rounded; the test allows 0.0051 mm when comparing against the intermediate model before placement. A separate synthetic nested transform test uses hand-computed positions and bounds; it is not a renderer or a physical printing calibration.

The result is diagnostic only, with topology and transfer flags false. This probe does not establish contour validity, cutting suitability, production approval, licensing clearance, or SVG support beyond the explicitly listed subset. It does not connect to CAD, persistence, real measurements, plotting or cutting.
