# Isolated C# curve and glyph vertical slice

This `net10.0-windows` console probe remains separate from `PatternPiece`, `ProjectDocument`, the production project codec, desktop editor, DXF, nesting, machine gateway and plotter. The production model is still a point list with vertex-attached visual notches. The probe is not a product integration or an automatic project migration.

The private diagnostic envelope `tekstilcad.synthetic.wpf-curves`, version 2, saves the full supplied `synthetic-curves.v2` source snapshot and independently modeled C# fields for each piece's seam, optional allowance and explicit closure, grainline/cut-on-fold annotation, and named glyph with affine matrix. It preserves the six source glyph/marker definitions, SVG annotation path, text and marker metadata through the source snapshot. Exact byte identity of the input JSON is not claimed: the test compares parsed values, including all source snapshot fields, separately against the checked-in synthetic source fixture and compares every modeled path, allowance, annotation and glyph field against that source. This detects data loss in this test, not the authenticity of an independently supplied or jointly modified source and model. The source document's explicit omitted items remain omitted; complete source SVG, source style, cutlist and a validated production boundary are not recovered.

The C# codec checks version, required and duplicate fields, size, roles, closed seam commands, finite control points, allowance presence and closure, known mark names and glyph matrices. It compares the typed fields against the snapshot, checks the source loss list, exact hashes of the six observed glyph definitions, source matrix/mark consistency, the SVG annotation metadata and rounded path against the transformed intermediate annotation. Altered or unsupported single-sided fields are rejected. These checks do not establish a trusted source provenance, simple topology, garment fit, machine safety or legal clearance. All production, topology and license flags remain false; the production reader rejects this envelope.

The probe creates unique synthetic files only under its ignored runtime directory, reopens its own version-2 file, and uses the actual existing `ProjectStorage` to read two generated legacy cases (unversioned and version-1). It also reads the checked-in `tests/TekstilCAD.Tests/Fixtures/studio-0.3-native.tcad` fixture, originally produced by the published 0.3 verification run; its known SHA-256 and file bytes are checked before and after loading. This is one genuine repository fixture, not proof that every historical version or user file is compatible. The fixture is never written. No user project is used.

WPF draws the seam and source allowance with `PathGeometry`/`BezierSegment`, preserving each allowance's open or closed state, and draws known notch/bnotch shapes under their saved matrices into a PNG without creating a window. It draws the SVG-rounded grainline or cut-on-fold annotation path under its saved source matrix, using source marker shapes oriented along the first and last segments. A zero-length direction fails closed. Diagnostic colors and widths are chosen by the probe; source styling and annotation text are **not** reproduced. The image labels allowance state for each piece. The preview viewport conservatively includes controls, glyph bounds and arrow extents; bitmap fitting is not physical print calibration. In the synthetic front the source allowance is open and a source line has zero length. The bitmap is labelled synthetic and not for production.

Experimental files are created with unique names and normal cleanup, and a partially written PNG is removed on a handled write failure. A process crash can leave temporary JSON or PNG files in the ignored runtime directory; this experiment does not demonstrate atomic production saving or recovery. Tests cover source-field comparisons and negative mismatches, changed glyph definitions, unknown commands, duplicate fields, missing data, source flags, timeouts, source SVG annotation, allowance closure, and independent arrow endpoint and tip calculations for the baseline, 2x scale/translation and anisotropic rotation. The old-format cases and read-only repository fixture are also exercised. Tests use only synthetic data and the isolated Node; no WearCAD file, plotter or personal measurement is touched. Third-party licensing remains unresolved.

The C# validation additionally requires distinct source annotation `pathId` values across all pieces and finite `anchor` and `sourceSvgAnchor` coordinates in the inclusive range ±100,000,000 mm. Tests change the snapshot and typed data together, including a large affine tolerance, to ensure those checks cannot be bypassed by internally consistent altered fields. These checks remain consistency guards, not source-authenticity proof.

This probe deliberately rejects an annotation whose first or last source segment has length below `1e-12` in source coordinates, during codec validation before rendering. It does not attempt SVG `orient="auto"` tangent fallback through repeated endpoints; an interior repeated point remains accepted if both endpoint directions are defined. This is a conservative supported subset, not full SVG marker behavior. Source markers default to `markerUnits="strokeWidth"`; this diagnostic drawing uses its selected one-unit annotation stroke and colors. If the source stylesheet changes stroke width, the marker display is not a pixel-identical reproduction of the original styling.
