# Sampled source evidence: v7 persistence design (not enabled)

Status: design only. The sampled DXF path remains preview-only. This design does not authorize import, editing, export, plotting, nesting, grading, or production use. Do not enable the reader or writer until the transform and output boundaries are enforced and tested together.

## Wire contract

Reserve version 7 as `[7, project]`; version 6 belongs to the separate marker draft and must not be interpreted as version 7. A v7 document may carry `SourceEvidence` per piece. Absence means no recorded sampled evidence; explicit null, incomplete objects, duplicate or unknown fields, invalid hashes, nonfinite/nonpositive scale or tolerance, and malformed text must reject the entire document. Require all six evidence fields, including explicit null for optional tolerance and review digest, when the object exists. Validate JSON shape before binding, then use the evidence constructor for value validation. Catch constructor failures and report invalid data. Do not turn missing fields into defaults. Reject `SourceEvidence` even when null in unversioned and v1–v5 documents; v6 remains rejected by this branch. Older readers reject the outer array version rather than silently dropping evidence. Unknown later versions also fail closed.

A v7 record can exist with or without v5 `ImportProvenance`. If present it must pass the complete v5 validation. Existing v5 documents still require it. Likewise all existing v1–v5 validation remains intact. Write v7 if any piece has evidence; otherwise retain the existing lowest applicable format. Null evidence must be omitted from ordinary pieces so existing formats do not acquire a new field. Enforce byte limits and validate before atomic replacement. Recovery envelopes must use the same project serializer and reader.

## In-memory and boundary contract

Evidence is immutable; clone can share the immutable value but must never drop it. Document session content equality must include all evidence fields, so evidence-only changes enter undo history and mark the document dirty. A reviewed digest is only an acknowledgement of the exact ordered geometry and closure; a matching digest is not production authorization. Review is invalidated on any geometry mutation, and derived/split/merged pieces must conservatively preserve source lineage or be rejected until a representation for multiple sources exists. A digest check alone is insufficient: geometry may change and later return to its previous coordinates. Do not permit untracked direct mutation to revalidate a previous review.

Before accepting sampled pieces into a document, enumerate and guard all transforms, cloning/duplicate/clipboard operations, grading, nesting, recovery, project load, and every DXF/plot/print/export route. An evidence-bearing v7 document must not be allowed through an unguarded output route, including direct library APIs and background workflows. Until those guards are complete, keep sampled import preview-only and reject opening v7 for use; merely storing evidence on PatternPiece would allow the existing output APIs to consume it. Keep the distinction between an absent provenance claim and verified original geometry explicit. Evidence must not silently disappear on any transformation.

## Verification before enabling

Cover v7 save/load and recovery round trips, all evidence fields and clones, session dirty/undo/redo, mixed ordinary and evidence-bearing pieces, v7 without document provenance, v5 with required provenance, v6 rejection, and every older format. Mutate JSON independently for missing/null/unknown/duplicate fields, invalid hashes/scales/tolerances, malformed geometry, oversized payloads, and unsupported versions; verify whole-document rejection and no destination replacement on failed save. Exercise source transformations including edit-then-revert, copy, split, merge and derived pieces, and assert review invalidation and lineage retention. Exercise every output entry point with evidence-bearing documents and assert fail-closed behavior, regardless of review digest. Confirm sampled preview still cannot be committed. Include compatibility fixtures produced by the actual v6 marker implementation once available; do not infer its shape here.
