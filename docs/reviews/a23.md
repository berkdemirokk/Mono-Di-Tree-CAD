# Agent 23 — security and data-loss review

Scope: read-only source review and read-only path probes. No builds, UI actions or WearCAD writes. 2026-10-31.

## P1: trailing-space alias bypasses protected-directory string checks

`src/TekstilCAD.FileFormats/ProjectStorage.cs:49-55`, duplicated in `src/TekstilCAD.Desktop/MainWindow.cs:154-158` and `src/TekstilCAD.MachineGateway/SimulationQueue.cs:108-113`.

Read-only PowerShell 7.6.5 evidence: `Path.GetFullPath("C:\WearCadfe \audit-never-written.tcad")` retains the space after WearCadfe; `Directory.Exists("C:\WearCadfe ")` returns true; `Get-Item` resolves that directory to `C:\WearCadfe` with ordinary Directory attributes, not ReparsePoint. Thus the current full-name blacklist comparison fails for a path Windows resolves inside protected data. No destination file was created. Reject trailing space/dot path segments before writing, and share the policy across all writers. A strict allowed workspace root is also consistent with AGENTS.md. Add a guard-only regression test.

An initial suspicion about the DOS alias WEARCA~1 was retracted: GetFullPath correctly expanded that alias in this environment. It is not a confirmed defect.

## P2: recycled process IDs can suppress and erase crash recovery

`src/TekstilCAD.Desktop/MainWindow.cs:35,82,194,200`.

Recovery filenames use only the process ID. Windows can reuse an ID after a crash. The next process then excludes the matching recovery filename from OfferRecovery, can overwrite it at its first autosave, or deletes it on clean close even with no edits. Use a random session ID plus PID metadata, and never remove another session's unaccepted recovery. Enumerate recovery errors inside a guarded boundary.

## P2: undo retains unbounded complete document copies

`src/TekstilCAD.Desktop/MainWindow.cs:29,96-101,126-127`.

Every committed edit deep-copies the whole project into an unbounded stack. With permitted 200,000 points, hundreds of node drags retain hundreds of MB to GB and can crash the application before autosave. Add a snapshot/byte budget or bounded command history; test eviction and retained undo/redo behavior.

## Positive observations and limits

Native persistence validates shape structure and finite coordinate bounds, uses a same-directory temporary file and replacement, and preserves the original if serialization/validation fails. Commit validates before modifying undo history and restores document state on failure. License verifier requires trusted public key, checks signature before claims, and includes expiry/device validation; no shipped private key observed. Machine module exposes only local-file simulation. Full physical-machine safety, concurrent malicious filesystem races and external format conformance were not certified by this review.

GUID recovery and bounded DocumentHistory replaced PID naming/unbounded stacks. Final regression and hidden desktop verification passed; see TEST_REPORT.md.
